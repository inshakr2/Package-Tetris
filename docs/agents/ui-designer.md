# UI Designer Role Memory

## Product Framing

Package Tetris V3 Core는 물류/현장 작업자가 모바일과 태블릿에서 실수 없이 적재 결과를 확인하고 백업까지 마치는 도구에서, 반복 업무를 위한 현장 작업대(workbench)로 확장되는 단계다. UI 판단은 예쁜 시각화보다 입력 실수 방지, 현재 상태 이해, 다음 행동 명확성, 복구 가능성을 우선한다.

## Integrated UI Principles

- 현장 언어 우선: `IndexedDB`, `v0`, `JSON 이동본`, `WebGL` 같은 기술어는 보조 설명으로 내리고, 주 UI는 `이 기기 저장`, `백업 파일`, `계산 결과`, `3D 보기`처럼 말한다.
- 4개 세로 섹션은 V3 Core 초반까지 유지한다. 작업대 UI로 전환할 때도 `공간 선택 -> 박스 등록 -> 실행 전 확인 -> 결과 확인` 흐름은 잃지 않는다.
- 모바일은 다음 행동 1개만 강하게 보여준다.
- 3D는 검토 보조, 2D는 위치 확인 근거로 유지한다.
- 저장 보호는 경고가 아니라 작업 안전장치로 표현한다.

## Screen Guidance

- 상단 보조 문구는 `이 기기에 자동 저장 · 백업 파일로 이동 가능`처럼 표현한다.
- 섹션 제목은 작업 동사 중심으로 직접화한다.
- 실행 전 확인 섹션은 현장 체크리스트처럼 문제 없음, 주의, 실행 불가를 구분하고 `결과 만들기` 하나를 크게 둔다.
- 결과 영역은 `공간 목록 / 3D·2D 뷰어 / 박스 범례`를 유지한다.
- 모바일 3D는 버튼 중심 검토를 기본으로 하며, 전체화면 `크게 보기`와 치수 오버레이는 V2 결과 확인 흐름에 포함한다.
- 절단면, 폭발도, 드래그 기반 수동 배치 편집은 후속 확장으로 둔다.
- 저장 보호 패널은 `이 기기 저장`, `백업 파일`, `브라우저 보호`의 3행 구조를 유지한다.

## Accessibility And Copy Standards

- 현장 기준 터치 타깃은 최소 48px 높이를 목표로 한다.
- 버튼 간격은 최소 8px 이상 둔다.
- 위험 행동과 주요 행동은 붙여놓지 않는다.
- 포커스 표시는 명확한 외곽선과 충분한 대비를 유지한다.
- 문구는 `상태 + 행동` 순서로 쓴다.
- 주요 본문은 14px 미만을 피하고, 모바일 조작 문구는 16px 전후로 맞춘다.

## V3 Core Increment Priorities

1. 보이는 UI를 바꾸기 전 컴포넌트 책임을 분리해 화면 단위 개편의 기준을 만든다.
2. 데스크톱 작업대, 태블릿 접이식 패널, 모바일 제약형 흐름을 분리해 설계한다.
3. 저장 박스 200개 이상을 전제로 검색/필터/선택/수량 편집 밀도를 높인다.
4. 결과와 추가 시뮬레이션은 긴 하단 이동보다 같은 작업 맥락 안에서 오가게 한다.
5. 위험 옵션과 추천 결과는 자동 적용처럼 보이지 않게 검토 중 상태를 분명히 표시한다.
